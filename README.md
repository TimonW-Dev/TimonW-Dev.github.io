# sysadminsuite.com

An all-in-one suite that brings essential everyday IT tools (binary/decimal converter, subnet calculator, MAC vendor lookup, …) together in one overview. Plain HTML, CSS and JavaScript.

## Run locally
Use the VS Code Live Server extension ("Go Live") and open http://127.0.0.1:5500/ (ES modules do not work via `file://`). Do not use a Python server or another local server.
