# sysadminsuite.com

An all-in-one suite that brings essential everyday IT tools (binary/decimal converter, subnet calculator, MAC vendor lookup, …) together in one overview. Plain HTML, CSS and JavaScript.

## Run locally
Test e.g with the VS-Code Live Server extension at http://127.0.0.1:5500/.
