APIs & third parties

Most tools run locally in your browser. Tools that contact an external service are listed here with the host, the data sent and the provider's privacy information. Such a listing does not replace any notice or consent required by law for that tool. Requests to any external host also reveal technical connection data, including your IP address, to that host.

ToolServiceData sentProvider privacy
CVE Lookup nvd.nist.gov With a correctly formatted CVE ID, “Lookup on NVD” puts the normalized CVE ID in the URL path /vuln/detail/<cve-id>. With a non-empty value that is not a correctly formatted CVE ID, “Search NVD” sends the entered search term in the keyword query parameter to /vuln/search. An empty input opens /vuln/search without a keyword. The selected page receives standard browser/request data. No request is made while typing. NIST site privacy
CVE Lookup www.cve.org With a correctly formatted CVE ID, “Lookup on CVE.org” puts the normalized CVE ID in the URL query parameter id. With a non-empty value that is not a correctly formatted CVE ID, “Search CVE.org” sends the entered search term in the query parameter to /CVERecord/SearchResults. An empty input opens the CVE.org home page without a search term. The selected page receives standard browser/request data. CVE.org's privacy policy describes its use of cookies and Google Analytics. No request is made while typing. CVE Program privacy policy
MAC Vendor Lookup raw.githubusercontent.com (GitHub, public repository TimonW-Dev/sysadminsuite-data) A request for the data file /TimonW-Dev/sysadminsuite-data/main/data/mac-vendors/<xx>.json, where <xx> are the first two hex characters of the entered address. The full address is not sent; the vendor is matched in your browser. Like any request, it also reveals your IP address and browser data to the host. GitHub privacy statement
